# Forever Addons Manager

Un gestionnaire d'addons pour WoW Forever, ultra léger : il remplace l'application CurseForge sans tourner en tâche de fond.

## Installer

1. Télécharge **`Forever-Addons-Manager-Setup.exe`** dans la [dernière version](https://github.com/mfarchitecture-ctrl/forever-addons-management/releases/latest).
2. Lance-le. Aucun droit administrateur n'est nécessaire.

Windows peut afficher « Windows a protégé votre ordinateur » car l'appli n'est pas signée : clique sur **Informations complémentaires** puis **Exécuter quand même**.

L'appli se lance ensuite avec Windows, discrète près de l'horloge, et te prévient quand une nouvelle version est disponible.

## Ajouter un addon

Sur le site CurseForge, clique sur **Install** : l'addon s'installe directement dans l'appli, dans sa version WoW Forever. Tu peux aussi coller son Project ID dans **+ Ajouter un addon**, ou lui donner un `.zip`.

## Vie privée

L'appli n'écoute que sur ton PC. Elle se connecte uniquement à CurseForge et GitHub pour vérifier et télécharger les mises à jour, et n'envoie rien sur toi. Ta collection et tes notes restent dans `%LOCALAPPDATA%\Forever Addons Manager`, et ne sont pas effacées si tu désinstalles l'appli.
